💡 Quick Reference:
• :hover → when mouse is over element
• :first-child → first child of its parent
• :focus → when element is focused (input, button, etc.)
• :nth-child(odd/even) → pattern-based selection
• ::before and ::after → insert content via CSS (note the double colon)
