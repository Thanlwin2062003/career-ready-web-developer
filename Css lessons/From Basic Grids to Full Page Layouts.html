📌 How grid-template-areas works: 
grid-template-areas:
  "nav-header  nav-header  nav-header  nav-side"
  "main-body   main-body   .           nav-side"
  "footer      footer      footer      footer";
• Every string = one row.
• Each quoted group defines columns (4 columns in this layout).
• nav-header spans first three columns → full width header except sidebar column.
• nav-side occupies the last column, stretching two rows (row 1 & row 2).
• . (dot) = empty cell → no element placed there.
• footer stretches across all four columns in the last row.
💡 Grid vs Flexbox — quick comparison
✅ Grid: Best for overall page structure (header/main/sidebar/footer). Handles both rows and columns with ease.
✅ Flexbox: Perfect for one-dimensional alignment (navigation bars, card rows, centering items). More flexible in content-driven layouts.
🎯 Together they are unstoppable: use grid for macro layout, flexbox for micro components.

🎓 Keep exploring: CSS Grid also supports inline-grid (similar to inline-block but grid-powered).
