My CSS Blueprint

This paragraph is inside the cabin. It has bold text and a generic span. Notice the color comes from the p selector, not the parent .cabin, because the p rule is more direct.

This paragraph has class="highlight". The crimson background and white text override the default p styles because a class is more specific than an element.

This paragraph has id="special-note". The gold-on-dark scheme overrides even the .highlight class because an ID has the highest specificity. You should only use one ID per page.

Framed Div: This div has a 4px double limegreen border. Even the <strong> text inside might not be bold if we set font-weight: normal; on the parent! (Spoiler: it still is, because browsers give <strong> its own bold rule. Try adding strong { font-weight: normal; } to override it.)

This text uses a wavy red line-through. It's a fun way to mark things as "done" or just visually noisy. Change text-transform in the CSS to see the difference.

I'm a footer paragraph outside the cabin div. I only have inline styles and browser defaults. I do NOT inherit the darkslateblue color from .cabin because I'm not inside it.
