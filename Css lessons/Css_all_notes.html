Text formatting tags:
• <b> - Bold without semantic importance
• <strong> - Bold with semantic importance
• <i> - Italic without emphasis
• <em> - Italic with emphasis
• <u> - Underlined text
• <mark> - Highlighted text
• <small> - Smaller text
• <del> - Deleted text (strikethrough)
• <ins> - Inserted text (underlined)

Anchor tag: <a> creates hyperlinks. href specifies the destination URL. target="_blank" opens the link in a new browser tab.
Image tag: <img> displays images. src specifies the image file path. alt provides alternative text for accessibility. width sets the image width.
