📚 Complete HTML & CSS Reference Guide

💡 How to use this guide: This document contains all essential HTML tags and CSS properties with examples. Use it as a quick reference while coding.

1. HTML Document Structure

Basic HTML Template

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <!-- Content goes here -->
</body>
</html>

Explanation: Every HTML document follows this structure. <!DOCTYPE> tells the browser it's HTML5. <head> contains metadata. <body> contains visible content.

10. CSS Box Model

Content Area
300px width

Box Model Components (from inside out):

  1. Content - The actual content (text, image, etc.)
  2. Padding - Space between content and border (transparent)
  3. Border - Line around padding and content
  4. Margin - Space outside the border (transparent)

Total Width = content + padding-left + padding-right + border-left + border-right

box-sizing: border-box makes width include padding and border

11. CSS Display Property

Common Display Values:

  • display: block - Takes full width, starts new line (div, p, h1-h6)
  • display: inline - Takes only needed width, no new line (span, a, img)
  • display: inline-block - Like inline but can set width/height
  • display: none - Removes element from flow entirely
  • display: flex - Creates flex container
  • display: grid - Creates grid container

12. CSS Position Property

Position Values:

  • position: static - Default, normal flow
  • position: relative - Positioned relative to normal position
  • position: absolute - Positioned relative to nearest positioned ancestor
  • position: fixed - Positioned relative to viewport (stays in place)
  • position: sticky - Toggles between relative and fixed based on scroll

Used with: top, right, bottom, left, z-index

Container Properties:

15. Responsive Design

Media Queries:

/* Mobile First Approach */
/* Base styles for mobile */

/* Tablet */
@media (min-width: 768px) {
    /* Styles for tablets and larger */
}

/* Desktop */
@media (min-width: 1024px) {
    /* Styles for desktop */
}

/* Print */
@media print {
    /* Styles for printing */
}

Responsive Units:

  • % - Percentage of parent
  • vw - Viewport width (1vw = 1% of viewport width)
  • vh - Viewport height
  • rem - Relative to root font size
  • em - Relative to parent font size

18. Transitions & Animations

Transitions:

.element {
    transition: property duration timing-function delay;
    /* Example: */
    transition: all 0.3s ease-in-out;
}

.element:hover {
    transform: scale(1.1);
    background-color: blue;
}

Animations:

@keyframes slideIn {
    from {
        transform: translateX(-100%);
        opacity: 0;
    }
    to {
        transform: translateX(0);
        opacity: 1;
    }
}

.element {
    animation: slideIn 1s ease-out;
}

19. CSS Transforms

Transform Functions:

  • translate(x, y) - Move element
  • rotate(deg) - Rotate element
  • scale(x, y) - Scale element
  • skew(x-deg, y-deg) - Skew element
  • matrix() - Combine transforms

Can be combined: transform: rotate(45deg) scale(1.5)

20. CSS Specificity

Specificity Hierarchy (lowest to highest):

  1. Universal selector (*) - 0,0,0,0
  2. Element selectors (p, div) - 0,0,0,1
  3. Class selectors (.class) - 0,0,1,0
  4. ID selectors (#id) - 0,1,0,0
  5. Inline styles - 1,0,0,0
  6. !important - Overrides everything

Best Practice: Use classes for styling, avoid !important and inline styles.

22. CSS Custom Properties (Variables)

:root {
    --primary-color: #3498db;
    --secondary-color: #2ecc71;
    --font-size: 16px;
    --spacing: 20px;
}

.element {
    color: var(--primary-color);
    font-size: var(--font-size);
    padding: var(--spacing);
}

Benefits: Reusable values, easy theme changes, maintainable code.

25. CSS Best Practices

Do's:

  • ✅ Use semantic HTML elements
  • ✅ Use classes instead of IDs for styling
  • ✅ Write mobile-first CSS
  • ✅ Use meaningful class names (BEM methodology)
  • ✅ Organize CSS with comments
  • ✅ Use shorthand properties when possible
  • ✅ Validate HTML and CSS
  • ✅ Test across browsers

Don'ts:

  • ❌ Don't use inline styles
  • ❌ Don't use !important unnecessarily
  • ❌ Don't use too many nested selectors
  • ❌ Don't forget about accessibility
  • ❌ Don't ignore performance
  • ❌ Don't use absolute units for everything
