📦 Lesson 1: Variables & Constants

Variables store data. const means the value won't change. Use camelCase naming!

// Good variable naming (camelCase)
const monthlyRent = 500;
const yearlyRent = monthlyRent * 12;

🎮 Try it yourself:

$500

💡 Change the monthly rent and see both values update automatically!

🖨️ Lesson 2: console.log()

console.log() prints values to the JavaScript Console (F12 or Right-click → Inspect → Console)

console.log(yearlyRent);  // Prints: 6000

💡 Lesson 3: Why Variables Matter

Imagine if your rent increased - change it in ONE place, and everything updates!

// BAD (hard to maintain):
const totalRentBad = 550 * 12 + 550 * 0.1;

// GOOD (clear & maintainable):
const monthlyRentGood = 550;
const yearlyRentGood = monthlyRentGood * 12;
const depositGood = monthlyRentGood * 0.1;
const totalCostGood = yearlyRentGood + depositGood;
